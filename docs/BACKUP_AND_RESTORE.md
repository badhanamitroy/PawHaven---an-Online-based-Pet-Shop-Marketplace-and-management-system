# PawHaven — Backup & Disaster Recovery Guide

Maintaining reliable backups of your PawHaven platform ensures business continuity and protects customer data.

---

## 1. What to Back Up

A complete PawHaven backup consists of three elements:

1. **The Database**:
   - For SQLite: `database/database.sqlite`
   - For MySQL: SQL dump generated by `mysqldump`
2. **Uploaded Media & Assets**:
   - `storage/app/public/` (contains pet photos and custom branding logos)
3. **Configuration & Encryption Keys**:
   - `.env` file (contains `APP_KEY`, which decrypts sessions, 2FA recovery codes, and credentials)

---

## 2. Backup Procedures

### A. SQLite Deployments

Because SQLite is stored in a single file, you can create atomic backups using SQLite's online backup API:

```bash
#!/bin/bash
BACKUP_DIR="/var/backups/pawhaven/$(date +%Y%m%d_%H%M%S)"
mkdir -p "$BACKUP_DIR"

# 1. Safely backup the SQLite database without locking active queries
sqlite3 /var/www/pawhaven/database/database.sqlite ".backup '$BACKUP_DIR/database.sqlite'"

# 2. Archive uploaded media files
tar -czf "$BACKUP_DIR/media_uploads.tar.gz" -C /var/www/pawhaven/storage/app public/

# 3. Securely copy the environment configuration
cp /var/www/pawhaven/.env "$BACKUP_DIR/.env"

# 4. Restrict permissions
chmod -R 600 "$BACKUP_DIR"
echo "Backup completed successfully at $BACKUP_DIR"
```

### B. MySQL Deployments

```bash
#!/bin/bash
BACKUP_DIR="/var/backups/pawhaven/$(date +%Y%m%d_%H%M%S)"
mkdir -p "$BACKUP_DIR"

# 1. Dump MySQL Database
mysqldump -u pawhaven_user -p'your_db_password' \
    --single-transaction \
    --quick \
    --lock-tables=false \
    pawhaven > "$BACKUP_DIR/pawhaven_db.sql"

# 2. Archive media uploads
tar -czf "$BACKUP_DIR/media_uploads.tar.gz" -C /var/www/pawhaven/storage/app public/

# 3. Copy environment configuration
cp /var/www/pawhaven/.env "$BACKUP_DIR/.env"

chmod -R 600 "$BACKUP_DIR"
```

## 3. Automated Cron Schedule

Add a daily automated backup to your server crontab:

```bash
# Edit crontab
crontab -e

# Run daily backup at 2:30 AM
30 2 * * * /usr/local/bin/pawhaven-backup.sh >> /var/log/pawhaven-backup.log 2>&1
```

## 4. Disaster Recovery & Restoration

### Step 1: Restore Source Files & Dependencies
```bash
cd /var/www/pawhaven
composer install --no-dev --optimize-autoloader
npm ci && npm run build
```

### Step 2: Restore Configuration
Copy your backed-up `.env` file back into `/var/www/pawhaven/.env`. Ensure `APP_KEY` matches your original key so encrypted data remains decipherable.

### Step 3: Restore Database

#### For SQLite:
```bash
cp /var/backups/pawhaven/20261031_023000/database.sqlite /var/www/pawhaven/database/database.sqlite
chown www-data:www-data /var/www/pawhaven/database/database.sqlite
chmod 664 /var/www/pawhaven/database/database.sqlite
```

#### For MySQL:
```bash
mysql -u pawhaven_user -p'your_db_password' pawhaven < /var/backups/pawhaven/20261031_023000/pawhaven_db.sql
```

### Step 4: Restore Media Uploads
```bash
tar -xzf /var/backups/pawhaven/20261031_023000/media_uploads.tar.gz -C /var/www/pawhaven/storage/app/
chown -R www-data:www-data /var/www/pawhaven/storage/app/public
php artisan storage:link
```

### Step 5: Post-Restore Verification
```bash
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan test --filter="SystemHealthTest"
```
